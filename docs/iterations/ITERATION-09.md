## 2. 宫灯一对（本轮唯一一次生成）

- 任务 `4564212`：中式宫灯（六角灯身、木质底座、铜框、红穗）
- `G1-Turbo`，约 40 秒，20.4MB，无动画
- 摆位：`(-7.7, 0, -1.1)` 与 `(7.7, 0, -1.1)`，高度 3.6，朝展台内转 0.5 rad
- 只下载一次，第二盏用 `clone(true)` 共享几何与材质，不重复占显存
- 两盏都加了碰撞体（由通用摆件逻辑外置，宫灯走自己的 `lantern-pair.js`）

累计 AI 生成：**3 次**（鼓、香炉、宫灯）。

## 3. 空间展品可点击

- 鼓、香炉、盘龙、宫灯都注册进 `hall.interactives`
- 画布上 `pointerdown/pointerup` 判断：位移 <6px 且 <600ms 才算点击，避免和 OrbitControls 拖动冲突
- 射线命中后复用热点导览的说明卡，显示英文标签、标题和 2–3 句说明
- 第一人称模式下不触发

## 5. 验证与风险

- `npm run build` 通过；
- 未跑浏览器实测。本轮改动面较大，重点确认：
  1. 默认机位下角色是否仍居中、有没有被宫灯挡住；
  2. 墙面/天花/柱子有没有悬空或穿模；
  3. 宫灯、香炉、鼓的体量关系是否合理；
  4. 点击展品是否稳定弹卡，拖动视角时不会误触。
- 所有位置与尺寸都集中在 `procedural-hall.js` 顶部和各个 ornament 文件里，可按观感微调。
