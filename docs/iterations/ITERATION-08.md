# ITERATION 08 · 大型铜香炉 + 摆件加载器收敛

- 日期：2026-11-02
- 触发原因：背景已有盘龙与鼓，但缺一件有体量的空间资产；同时鼓的加载代码可以复用。
- 本轮目标：只花一次生成任务，加一件大型摆件，并把静态摆件的加载逻辑收敛成公共模块。

---

## 1. 又一次（也是本轮唯一一次）生成

- 端点：`https://api.aholo3d.cn/lux3d/v1/generate/text-to-3d/task/create`
- 参数同上一轮：`G1-Turbo`、`glb`、`enablePbr`
- Prompt：大型中式**铜香炉（鼎）**，三足、双耳、饕餮纹、深铜绿锈
- 任务 ID：`4564131`，约 70 秒完成
- 产物：21.5MB，1 mesh，无动画，包围盒 0.29×0.35×0.30

累计用量：**2 次生成任务**（醒狮鼓 + 铜香炉），其余都是免费的 `task/list` / `task/get` 轮询。

## 2. 加载器收敛

新增 `src/environment/ornament.js` 的 `createStaticOrnament()`，统一处理：

- 延迟加载（默认 3s，可配）
- 按高度归一化、水平居中、底面贴地
- 投影/接收阴影、环境反射强度
- 可选的轻微浮动（本轮两件都没用）
- 销毁时释放几何与贴图

`drum-ornament.js` 改成一行配置的薄封装，`censer-ornament.js` 同理。以后再加摆件只需要写一个配置。

## 5. 验证与风险

- `npm run build` 通过；
- 未跑浏览器实测，需要确认：
  1. 香炉是否落在展台右前方、体量是否合适（2.2 单位，约角色 2/3 高）；
  2. 与鼓是否左右平衡、有没有挡住角色；
  3. 第一人称能否被两件摆件挡住（碰撞半径已加）。
- 两件都是 AI 生成资产，细节质量取决于生成结果；如果某一侧观感不好，优先调 `height` / `position`，不建议为此再花额度重生成。
