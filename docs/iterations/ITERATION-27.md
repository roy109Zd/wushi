# ITERATION 27 · 移除程序化店铺，只留生成建筑；道具与桌子对位

- 日期：2026-11-03
- 触发原因：街市两侧的长方体店铺太简陋；桌面道具与桌子穿插。
- 结果：程序化店铺全部删除；酒楼排成两列；桌面道具抬到桌面高度。

---

## 1. 删除内容

- `buildShopRow()` 的两处调用移除，街市不再有长方体店铺与发光窗；
- 相应地，临街碰撞体从 `z 11.2~16` 收到 `8.5~15`（生成建筑的位置）。

## 2. 保留 / 新增的生成建筑

| 资产 | 摆放 | 高度 |
|---|---|---|
| 酒楼 `street-inn` | 6 件，`x = 25 / 33 / 41`，`z = ±12.5` | 9.5 |
| 阁楼 `street-pavilion` | `(33, 18.5)` | 10 |
| 门楼 `street-gate` | `(45.5, 0)` | 12 |

## 3. 道具与桌子对位

`loadLandmark()` 新增 `y` 参数，桌面道具统一抬到 `y = 1.02`（桌面高 1.01）：

| 道具 | 高度 | 说明 |
|---|---|---|
| 酒坛 | 0.80 | 原 1.1，缩小后不穿桌 |
| 生菜 | 0.75 | 原 1.0 |
| 鼓 | 0.95 | 原 1.4 |
| 香炉 | 1.15 | 原 1.8，仍偏大但可接受 |
| 宫灯 | 1.70 | 原 2.6 |

## 4. 观察

从传送落点朝街尾看：左侧桌上香炉、右侧桌上鼓、正前方红色门楼，脚下有生菜，
两侧是酒楼立面与灯笼。长方体店铺已不再出现。

## 5. 待确认

- 若希望正面就能看到连续酒楼立面，可把两列向街心收到 `z = ±9`。
