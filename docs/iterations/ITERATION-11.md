# ITERATION 11 · 侧室与门洞 + 更多屏风 + 角色漫游

- 日期：2026-11-02
- 触发原因：屏风太少、展厅内部没有真正的房间结构；龙的朝向反了；希望舞狮本人能走进空间探索。
- 本轮目标：用程序化几何做隔断与门洞，并新增第三人称角色漫游模式。不消耗生成额度。

---

## 1. 龙的方向

原来 `rotation.y = -angle + π/2`，龙头朝后。改成 `-angle - π/2`，整体转 180°，现在是头朝前进方向。

## 2. 两个侧室（有门洞）

`createSideRoom(mats, side)` 生成：

- 纵向隔墙：`x = ±9.0`，从 `z = -8.6` 到 `-18.4`，高 4.6（不到顶，保持通透）
- 横向墙：`z = -8.6`，中间留 2.2 宽门洞，门洞正对壁龛轴线
- 门框、门楣、铜质门槛线
- 壁龛成为房间的端景

两个侧室各有 3 个矩形碰撞体（隔墙 + 两段横墙），门洞可通行。原来后区的壁龛，现在变成了"走进小房间才能看"的展品。

## 3. 屏风加到四片

原来只有前区两片斜屏，现在再加两片贴墙的：

| 屏风 | 位置 | 朝向 | 作用 |
|---|---|---|---|
| 前左 | (-12.8, 0, 3.2) | 1.15 | 收窄入口通道 |
| 前右 | (12.8, 0, 3.2) | -1.15 | 对称 |
| 侧左 | (-15.4, 0, 7.4) | 1.55 | 贴墙延伸前区界面 |
| 侧右 | (15.4, 0, 7.4) | -1.55 | 对称 |

## 4. 角色漫游（第三种模式）

顶部模式切换新增 **Roam**：

- `stageRoot` 直接当角色容器移动，播 Walk / Run / Jump 骨骼动画
- WASD 移动（2.4 单位/秒），Shift 奔跑（4.9），空格跳跃，Q / Esc 退出
- 相机第三人称跟随：站在角色身后 8 单位、高 4.4，位置做指数平滑
- 移动时按方向转身，撞到隔墙/摆件会停住（复用第一人称的碰撞体）
- 停下时结束动画、显示当前材质的静态模型
- 进入时自动暂停自动旋转；角色漫游期间隐藏部位热点、机位条，并屏蔽 1/2/3 等快捷键

实现放在 `src/roam.js`，与 `ViewerController` 解耦：漫游期间给 ViewerController 挂 `suspended`，它的 update 直接返回，不会和跟随相机打架。

## 6. 验证与风险

- `npm run build` 通过；
- 未跑浏览器实测，重点确认：
  1. 两个侧室门洞是否真的能走进去，门框有没有穿模；
  2. 屏风是否挡住主角或鼓/香炉；
  3. 角色漫游时相机是否跟手、转身是否自然；
  4. 漫游中撞墙是否停住、退出后相机是否复位；
  5. 龙是否头朝前。
