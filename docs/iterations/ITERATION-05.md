# ITERATION 05 · 部位热点导览

- 日期：2026-11-01
- 触发原因：只能整体看模型，缺少「可读」的细节入口。热点能把形体讲成内容。
- 本轮目标：在狮头祥云、卷曲鬃毛、盘扣、衣褶、布鞋五个位置挂可点击标记，点击后相机推近并弹出说明。

---

## 1. 坐标怎么标出来的

没有手工在编辑器里点点，而是直接从 `醒狮.glb` 的顶点数据里算：

1. 读取 POSITION 顶点，得到包围盒：`x[-0.062,0.062] y[-0.090,0.090] z[-0.049,0.049]`；
2. 按页面里的归一化规则换算：缩放 `3.25 / 高度`、X/Z 居中、脚底 y=0；
3. 在目标高度区间里筛顶点，取 **z 最大（最靠前）** 的那个点作为表面点；
4. 再沿法线方向外扩一点，避免标记陷进表面。

最终坐标（模型局部空间，正面朝 +Z）：

| # | 部位 | position | 相机偏移 |
|---|---|---|---|
| 01 | 祥云纹（额） | (-0.18, 2.74, 0.70) | (0.5, 0.22, 2.5) |
| 02 | 卷曲鬃毛 | (-0.34, 2.31, 0.60) | (-1.0, 0.28, 2.15) |
| 03 | 盘扣 | (0.12, 1.77, 0.68) | (0.65, 0.08, 2.3) |
| 04 | 衣褶 | (-0.14, 0.60, 0.30) | (0.45, 0.5, 2.45) |
| 05 | 布鞋 | (-0.81, 0.12, 0.12) | (-0.5, 0.78, 2.25) |

相机偏移是相对于该点的**局部**偏移，所以无论模型转到什么角度，聚焦时都会绕到这一侧的正面，而不是从背后看。

## 2. 交互

- 标记是 HTML 按钮，每帧把锚点投影到屏幕坐标后定位，所以文字始终正对观众、不会随模型倾斜；
- 标记挂在 `stageRoot` 下，自动旋转时会跟着模型走；
- 根据「点相对模型中心是否朝向相机」做了一个简单的背面剔除，转到背后会自动隐藏；
- 点击标记：
  1. 如果正在自动旋转，先暂停（否则目标点会一直转走）；
  2. `viewerControls.focusOn()` 把相机补间到该点的近景；
  3. 弹出底部说明卡：部位编号、英文标签、标题、2–3 句说明；
- 卡片里有「上一处 / 下一处 / 返回全景 / 关闭」，可以当作一条 5 站的小导览；
- 切机位、复位视角、进入第一人称时自动关闭卡片；
- 为配合近景，`OrbitControls.minDistance` 从 4.2 放宽到 1.8，否则相机会被弹回。

## 3. 文案

五段说明都落在「为什么这么雕」上：

- **祥云纹**：云纹抬高眼窝上方的体块，正面打光形成「眉骨」阴影，让表情更精神；
- **卷曲鬃毛**：每缕单独成形再叠压，素模阶段就能看出厚度，材质迁移后高光才顺着卷曲亮起来；
- **盘扣**：最小的一个「建筑」，用来检验小尺度浮雕在 19.7 万面模型上能不能站住；
- **衣褶**：褶皱跟着身体扭转走，形成从腰指向脚背的引导线；
- **布鞋**：圆头厚底让双脚「压得住」，也给七段骨骼动画留出重心余量。

## 5. 验证与风险

- `npm run build` 通过；
- 坐标是几何估算，如果标记看起来偏了半个头或落在衣服外侧，直接改 `src/hotspots.js` 里的 `position` 即可，不需要动逻辑；
- 未跑浏览器实测，建议确认：
  1. 五个点是否都落在对应的部位上；
  2. 点击后相机是否绕到正面近景、模型没有穿帮；
  3. 自动旋转时标记是否跟随、转到背面是否隐藏；
  4. 移动端卡片是否挡住模型（当前放在底部 118px）。
