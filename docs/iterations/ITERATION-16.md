# ITERATION 16 · 练功房（训练篇章）

- 日期：2026-11-02
- 触发原因：故事长廊只讲了「表演」，没讲台下的训练。
- 本轮目标：在右侧展室里做一间练功房，四个训练器械 + 新栏。不消耗生成额度。

---

## 1. 四个训练篇章

| # | 训练 | 器械 | 讲什么 |
|---|---|---|---|
| T1 | 扎马步 | 双柱横杆 | 四平马步半小时，腿稳了动作才有根 |
| T2 | 石锁 | 石锁 | 狮头七八斤到十几斤，练腕力与肩背 |
| T3 | 走桩 | 三根高桩 | 从矮桩到高桩，摔出来的腾跃 |
| T4 | 鼓点 | 小鼓 + 鼓槌 | 狮头狮尾靠鼓点对齐，先数拍再上鼓 |

每件器械放在圆木垫上，位置在右侧展室 `x = 12.8`，`z = -10.4 / -12.6 / -14.8 / -16.9`。

## 2. 新栏：练功房

右侧控制栏在「舞狮故事」下方新增 `TRAINING ROOM / 练功房`：

- 四行按钮（T1–T4），点击后相机飞近器械并弹出说明卡
- 场景里也可以直接点击器械，走同一套交互

## 4. 验证与风险

- `npm run build` 通过；
- 未跑浏览器实测，重点确认：
  1. 四件器械是否都在右侧展室里、没有穿墙；
  2. 相机飞近时会不会穿进墙里（机位固定在器械正前方 2.8 单位）；
  3. 与原有壁龛是否重叠。
