# ITERATION 10 · 提亮墙面 + 盘龙巡游 + 壁龛 + 折屏

- 日期：2026-11-02
- 触发原因：墙面偏暗、盘龙位置不理想，需要更多可探索内容，并让空间本身更有层次。
- 本轮目标：纯代码 + 程序化几何，不再消耗生成额度。

---

## 1. 墙面提亮

四层叠加，避免只靠调亮一个参数：

| 做法 | 说明 |
|---|---|
| 墙体材质 | 颜色 `0x1b0908 → 0x4a2720`，加 `emissive 0x3a1a0e`（0.75），墙面自身带一点底光 |
| 洗墙光 | 新增 3 盏不投影的 `PointLight`（后墙 + 左右墙），强度 55/40/40，范围 26 |
| 檐口灯带 | 用 `MeshBasicMaterial` 做三条发光细条（后墙 + 两侧），模拟 LED 洗墙，几乎零成本 |
| 全局光 | 墨夜：半球 1.25→1.8、环境 0.42→0.68、补光 1.5→1.85；雾密度 0.014→0.011 |

月白与朱砂两套光调也同步提亮，避免只有默认布景变亮。

## 2. 盘龙改成巡游

原来固定在月亮门前，现在沿展厅上空**缓慢盘旋**：

- 半径 8.6，绕中心 (-2) 一周约 60 秒
- 高度 6.6，叠加 ±0.14 的起伏
- 朝向沿切线，半径避开 ±10.2 的柱子

这样既解决了"位置尴尬"，也让静态空间一直有东西在动。

## 3. 可探索内容

### 3.1 两侧壁龛

后墙月亮门左右各一个壁龛（x = ±11.8）：

- 木框 + 石台 + 铜环 + 一枚缓慢发光的"材质砖"
- 各带一盏不投影的小点光
- 点击后相机推近并弹出说明

### 3.2 折屏

新增两片五折屏风（5.0 × 3.2）：

- 左屏 `(-12.8, 0, 3.2)` 转 1.15 rad，右屏对称
- 把展厅前区收窄成一条通道，形成"先抑后扬"的入口序列
- 屏面用宣纸材质（双面、微自发光）

### 3.3 点击即导览

鼓、香炉、宫灯、两处壁龛、两片屏风都带 `focus` 目标：点击后不只是弹卡，相机会补间到展品近景。盘龙因为一直在动，只弹卡不移动相机。

## 5. 验证

- `npm run build` 通过；
- 未跑浏览器实测，重点确认：
  1. 墙面是否够亮但不过曝（若过亮，先降 `emissiveIntensity` 或洗墙光强度）；
  2. 盘龙盘旋是否与柱子/匾额穿插；
  3. 折屏是否挡住主角或鼓/香炉；
  4. 点击壁龛/屏风是否推近并弹卡。
