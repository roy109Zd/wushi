# ITERATION 26 · 街市填充：摊位、道具、门楼与灯光

- 日期：2026-11-03
- 触发原因：街市太单一，只有一个灯；之前生成的门楼/酒楼/阁楼都不见了。
- 结果：街市有连续摊位、道具与门楼；曝光提亮，走到街心能看见内容。

---

## 1. 摊位

沿街五处摊位（木台 + 四腿 + 酒旗 + 布幡），位置贴近街心，保证平视可见：

```
(24.5, 4.2) (29.5, -3.8) (34.5, 4.0) (39.5, -3.6) (43.5, 3.8)
```

## 2. 生成道具

| 道具 | 位置 |
|---|---|
| `story-drunk.glb` 酒坛 | 24.5, 4.2 |
| `story-green.glb` 生菜 | 29.5, -3.8 |
| `drum.glb` 鼓 | 34.5, 4.0 |
| `censer.glb` 香炉 | 39.5, -3.6 |
| `lantern.glb` 宫灯 | 43.5, 3.8 |

## 3. 生成建筑

- 门楼 `street-gate.glb`：`(45.5, 0)`，高 12，正对街道尽头
- 酒楼 `street-inn.glb`：`(34, 14.5)` 与 `(40, -14.5)`，高 10
- 阁楼 `street-pavilion.glb`：`(24, 15.5)`，高 9

## 4. 曝光

- 方向光 4.2、半球光 2.6、环境光 0.55
- 沿街 7 盏暖色点光（强度 90、距离 30）
- 店铺正立面增加两扇发光窗（MeshBasicMaterial），避免「整条街只有黑墙」

## 5. 观察结果

从传送落点 `(30.5, 0)` 朝街尾看：

- 左右各有一个摊位，能看清香炉与鼓；
- 正前方是红色门楼与石基；
- 两侧店铺仍是深色体块，酒楼/阁楼被店铺挡住，只在高处露出一部分。

## 6. 下一步

- 若要让酒楼/阁楼明显：把外侧店铺压低或后移，把生成建筑放到临街位置；
- 或直接把两侧店铺替换成生成建筑（需要注意它们自带的背景平面）。
