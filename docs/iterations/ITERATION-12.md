# ITERATION 12 · 角色相对移动 + 门外街市 + 行人

- 日期：2026-11-02
- 触发原因：漫游要按角色朝向来控制；空间物体要能挡住人物；希望推开一扇门进入长安风格的街头。
- 本轮目标：改操作、补碰撞、加门与街市。不消耗生成额度（SpatialGen 空间资产仍未到位，街市先用程序化几何搭）。

---

## 1. 操作改成角色相对

原来 WASD 是世界方向平移，现在改成坦克式：

- `W / S`：沿角色当前朝向前进 / 后退
- `A / D`：原地左转 / 右转（2.3 rad/s）
- `Shift`：奔跑（4.9），平时走路（2.4）
- `空格`：跳跃；`Q / Esc`：退出

相机始终跟在角色背后，转身时镜头跟着绕。

## 2. 碰撞补齐

- 屏风四片、宫灯两盏都补了圆形碰撞体，人物不会穿过去
- 角色碰撞半径从 0.32 提到 **0.62**，避免视觉上"半个身子插进模型"
- 侧室墙、摆件、街市店铺与城门都带碰撞

## 3. 门与街市

在展厅**右墙**开门（门洞 3.2 宽、3.9 高，带木框和铜门槛），推开后是一条东西向的小街：

- 夯土路面 + 中间车辙石板路
- 两排各 3 间木构店铺：墙体、双坡瓦顶、门板、檐下红灯笼
- 街尾一座城门（墙体 + 门楼 + 门洞）
- 三盏街灯 + 两盏暖色点光
- 展台一侧仍可正常参观，出门后是另一套空间感受

街市是程序化搭的（`src/environment/street.js`），因为群核 / SpatialGen 的空间 GLB 仍然拿不到。如果之后拿到，可以直接替换 `buildEnvironment()` 的资产，街市这套几何作为保底。

## 4. 街头行人

三具独立行人（不与场景合并）：

- 圆袍 + 头 + 幞头 + 两条手臂，颜色各异
- 沿街往返行走，速度 0.85–1.25，到端点转身
- 行走时有上下起伏，手臂前后摆动
- 由 `street.update()` 每帧驱动，和展厅、角色完全独立

## 5. 涉及文件

| 文件 | 改动 |
|---|---|
| `src/environment/street.js` | 新增，街市几何 + 行人 + 碰撞 + 更新 |
| `src/environment/procedural-hall.js` | 右墙开门、接街市、补屏风/宫灯碰撞、扩展边界 |
| `src/roam.js` | 坦克式移动、转身、碰撞半径 0.62 |
| `src/camera-controls.js` | `collides()` 支持自定义半径 |
| `src/config.js` | 探索边界扩展到街市 |

## 6. 验证与风险

- `npm run build` 通过；
- 未跑浏览器实测，重点确认：
  1. 能否从门洞走出去、门框是否穿模；
  2. 街市是否够亮（只加了两盏点光，可能偏暗）；
  3. 行人是否在街上往返、会不会走出店铺；
  4. 转身 + 前进是否顺手，镜头跟随是否眩晕；
  5. 屏风/宫灯是否真的挡住角色。
