# ITERATION 01 · 自建展示界面 + 精选模型 + 玩法打磨

- 日期：2026-11-01
- 版本状态：开发中（本地 `npm run dev` 可直接看）
- 触发原因：群核 / SpatialGen 的空间 GLB 暂时导不出来，原「空间实验」面板无法验收；模型单文件 13–15MB，八套材质全量展示加载过慢。
- 本轮目标：不依赖外部空间资产，先把「一尊醒狮 + 三种材质 + 三套光调 + 三个机位」的展示闭环做扎实。

---

## 1. 本轮改了什么

### 1.1 展示界面：空间实验 → 布景光调

| 原来 | 现在 |
|---|---|
| 右侧「空间实验」面板：导入空间 GLB、恢复临时展厅、进入空间探索 | 右侧「布景光调」面板：墨夜·聚光 / 月白·影棚 / 朱砂·堂会 三套光调 |
| 空间导入 / 恢复按钮常驻但无资产可用 | 移除死入口，保留程序化东方展厅作为唯一舞台 |
| `spatialgen.js` 与 `buildEnvironment()` 仍会读 `VITE_SPATIALGEN_MANIFEST_URL` | 代码保留，空间资产到位后可直接回归，无需改 UI |

光调不是贴图滤镜，改的是场景真实光照：

- `src/scene.js` 新增 `MOOD_SETTINGS`（背景色、雾色与雾浓度、曝光、环境光强度、四盏灯的颜色与强度）与 `sceneContext.setMood(id)`；
- 三套光调的差异：墨夜偏暖金顶光、月白转冷白柔光、朱砂加暖红侧逆光；
- `body[data-mood]` 同步切换页面四周的氛围叠层，避免「灯光变冷、压暗层仍是暖红」的割裂；
- 切换只改灯光参数，不重新加载模型，基本零耗时。

### 1.2 精选模型：只留三套

- `MATERIAL_ORDER` 维持 `original / metal / ceramic` 三套，首屏只加载当前素模（约 15MB），其余按需加载；
- 另外五套（大理石、澄明玻璃、彩璃、白瓷、羊毛毡）的配置与 GLB 保留在仓库，改一行 `MATERIAL_ORDER` 即可重新启用；
- 页面上的材质计数、底部序列、`/ 03` 全部对齐到三套，不再出现「文案写 03、角标写 08」的矛盾。

### 1.3 玩法：机位预设 + 快捷键

- 新增 `VIEW_PRESETS`（`src/config.js`）与「全景 / 狮首 / 侧身」机位条，位于底部控制条上方；
- `ViewerController.focusPreset()` 用与「复位视角」同一套补间移动相机；用户一旦拖动，立即交还 OrbitControls 并取消机位高亮，不会和手动操作打架；
- 快捷键（`src/main.js`）：
  - `1 / 2 / 3` 切材质
  - `V` 循环切机位
  - `R` 复位全景
  - `A` 自动旋转开关
  - 输入框聚焦时、以及第一人称漫游模式下自动禁用，避免和 WASD 冲突；
- 左侧展签新增一行快捷键提示；
- 五段策展导览扩为六段，新增「布景」一章，点击会聚焦到布景面板，方便现场讲解。

### 1.4 性能与加载手感

- `THREE.Cache.enabled = true`：材质被 LRU 淘汰后再次切回不必重新走网络；
- 首屏完成后空闲时预加载下一套材质（`preloadNearby(1)`），切材质时大概率命中缓存；
- 已下载过的材质切换不再弹全屏加载遮罩，直接走淡入淡出；只有首次下载某套材质时才显示进度；
- 保持原有策略：材质缓存 2 套、动作缓存 2 套、低性能设备降像素比与阴影。

### 1.5 顺手修掉的隐藏 Bug

`src/ui.js` 里 `$` 是 `querySelector`（返回单个元素），但 `this.materialButtons`、`[data-chapter]`、`.material-tags button` 三处直接对它调用 `.forEach`。这会让 `UIManager` 构造函数在绑定事件时抛 `TypeError`，页面停在 0% 加载态。已全部改为 `$$`（`querySelectorAll`）。

> 也就是说，本轮之前从仓库拉下来的版本其实是打不开的，不只是「空间没接」。

### 1.6 布局修正

- 底部控制条原来 `left: calc(50% - 170px)` 再叠加 `translateX(-50%)`，等于偏移了两次，会压住左侧展签。改成桌面端真正居中，宽度按两侧面板留白收缩；1080px 以下左展签隐藏后，再整体左移半个右栏宽度；
- 机位条跟随控制条对齐；820px 以下两者一起隐藏，移动端仍用原面板开合逻辑。

## 3. 验证情况

- `npm run build` 通过（24 modules，JS 约 701KB / gzip 187KB，CSS 约 32KB）；
- 用无头 Edge + CDP 实际打开过构建产物：首屏渲染完成、模型可加载、布景与机位按钮点击生效、`key:2` 可切到鎏金；
- 过程中发现并修掉了 1.5 的 `TypeError`；
- 最后一轮微调（月白提亮、狮首机位后撤、机位条字号）之后只做了语法检查，未再复跑构建与截图。
