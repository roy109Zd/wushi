# ITERATION 04 · 材质档案 + 技术视图

- 日期：2026-11-01
- 触发原因：Demo 里可看的内容偏少——一尊模型 + 两块面板，材质只有名字和一行简介，缺少「可读」的东西。
- 本轮目标：不动模型资产，把信息密度做厚：每套材质有档案，同一件作品能拆成网格 / 法线 / 骨架来看。

## 1. 材质档案（MATERIAL DOSSIER）

新增 `src/dossier.js`，为 8 套材质各写一份展签：

| 字段 | 内容 |
|---|---|
| `craft` | 工艺来源，如「失蜡法铜胎 · 手工鎏金」 |
| `story` | 2–3 句策展语，讲这套材质在叙事里承担什么 |
| `palette` | 3 个色值，界面上渲染成色板 |
| `params` | 金属度 / 粗糙度 / 通透度，渲染成参数条（只用于展示，不参与渲染） |
| `mood` | 推荐光调，可一键套用 |
| `tags` | 3 个短标签 |

界面位置：材质实验室面板内、材质列表下方，随当前材质切换实时更新。

配套调整：

- 材质列表加了 `max-height: 286px` 与细滚动条，8 张卡片不会把档案挤到屏幕外；
- 点「推荐光调」直接调用已有的 `applyMood()`，档案和布景联动。

## 2. 技术视图（TECHNICAL VIEW）

新增面板与 4 个视图模式（`src/config.js` 的 `VIEW_MODES`）：

| 模式 | 实现 | 说明 |
|---|---|---|
| 材质 SHADED | 正常 PBR | 默认 |
| 线框 WIREFRAME | `material.wireframe = true` | 看 197,135 个三角面的布线密度 |
| 法线 NORMAL | 换成共享的 `MeshNormalMaterial` | 用颜色表示朝向，浮雕与转折最清楚 |
| 骨骼 SKELETON | `THREE.SkeletonHelper` | 只在动作播放时可用 |

关键实现（`src/main.js`）：

- `currentModels()` 同时收集「当前材质模型」和「正在播放的动作模型」，两种状态下视图都生效；
- 切换前先 `restoreMaterials()` 还原，避免法线材质或线框状态被带进缓存里的旧模型；
- 法线模式把原 material 存在 `WeakMap` 里，退出时精确还原；
- 骨骼模式的 helper 每次重建、退出即 dispose，不累积；
- 切材质、开始动作、动作结束、回待机都会重新应用一次视图，保证状态一致。
