# ITERATION 21 · 侧栏传送门、生成门楼与阁楼、街市尺度

- 日期：2026-11-02
- 触发原因：需要从侧栏直接进入街市；街市场景过于简陋；建筑与人物相对舞狮角色偏小。
- 结果：三项都已落地。

---

## 1. 侧栏传送门

右侧控制栏新增 `PORTAL / 街市传送`：

- 点击「传送至街市」→ 直接进入 Roam，并落在街市中段 `(30.5, 0)`，朝街尾方向；
- 提示「已传送至长安街市：W/S 前进，A/D 转身，Q 退出」；
- 同时兼容原来的步行出门（走过朱门仍然进入街市，只是不再触发 3DGS 覆盖层）。

## 2. 生成建筑

用 Lux3D `text-to-3d` 新增两件大型资产：

| 资产 | 提示词要点 | 任务 | 体积 | 摆放 |
|---|---|---|---|---|
| 城楼门楼 | 双层飞檐、灰瓦、朱红立柱、拱门 | 4587284 | 23.1MB | `(35.2, 0)`，高 11，朝街内 |
| 两层阁楼 | 木构、飞檐翘角、二层回廊 | 4587286 | 20.2MB | `(27, 13.5)`，高 8 |

接入方式：`street.js` 的 `loadLandmark()` 按高度归一化、居中、落地；加载失败只告警，不影响程序化街市。

## 3. 尺度调整

之前店铺只有 3.2 单位高，而舞狮角色 3.25 单位——相当于「狮子和房子一样高」。本轮整体放大：

| 对象 | 原来 | 现在 |
|---|---|---|
| 店铺墙体 | 4.6 × 3.2 × 3.4 | 6.2 × 5.8 × 4.6 |
| 店铺屋顶 | 5.2 宽 | 7.2 宽 |
| 门板 | 1.2 × 2.1 | 1.6 × 3.8 |
| 街灯杆 | 3.0 高 | 5.4 高 |
| 城门墙 | 7.2 高 | 9.6 高 |
| 行人 | 约 1.7 单位 | 约 2.7 单位（scale 1.6） |
| 门楼 / 阁楼 | — | 11 / 8 单位 |

同时把三个行人的行走线从街心 `z = -2.2 / 2.6 / 0.6` 挪到 `-5.6 / 5.9 / 7.2`，避免传送落点正好撞上一个行人。

## 4. 验证

- 构建通过；
- 无头浏览器：点击传送门后 `mode = roam`、坐标 `x = 30.5`、控制台 0 错误；
- 截图可见街市纵深、门楼轮廓与行人，但门楼的生成结果偏「红幔」质感，是否可用需要你实机判断。

## 5. 待确认

- 门楼朝向与尺度是估的，如果比例或方向不对，改 `street.js` 里 `loadLandmark` 的 `height / rotationY`；
- 阁楼目前只放在一侧，若需要成对可以再复制一份到 `z = -13.5`。
