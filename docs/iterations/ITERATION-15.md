# ITERATION 15 · 舞狮故事长廊（新栏）

- 日期：2026-11-02
- 触发原因：希望把舞狮背后的故事用 3D 讲清楚，并新增一个主题栏目。
- 本轮目标：在展厅左侧做一条五章故事长廊，配独立的「舞狮故事」面板。不消耗生成额度。

---

## 1. 五章叙事

| # | 章节 | 3D 道具 | 讲什么 |
|---|---|---|---|
| 01 | 点睛 | 朱砂笔 + 朱砂碟 | 新狮头要开光点眼才算「活」 |
| 02 | 起势 | 一对鼓槌 | 三通鼓里从睡到醒、从静到动 |
| 03 | 采青 | 生菜 + 红包 | 试探、犹豫、跃起、吐青还主家 |
| 04 | 醉狮 | 酒坛 | 偷酒、脚步虚浮、醉倒在地 |
| 05 | 收势 | 绣球 | 退步抱拳，收得住才算结束 |

每座展台：石质基座 + 铜环 + 符号化道具 + 一块墙面说明牌（Canvas 文字，`index + 标题 + 英文`）。

## 2. 空间位置

- 长廊沿 **左墙** 排开：`x = -17.4`，`z = -1 / 2 / 5 / 8 / 11`
- 说明牌贴墙 `x = -19.75`，朝厅内
- 为让开这条视线，**移除了左侧折屏**（屏风从两片减到一片，只剩右侧）
- 探索边界 `minX` 从 -15.4 扩到 **-19.7**，可以真的走进长廊
- 五座展台都有半径 0.85 的碰撞体

## 3. 新栏：舞狮故事

右侧控制栏新增 `STORY IN 3D / 舞狮故事` 面板：

- 五行章节按钮，显示编号、标题、英文
- 点击后：相机补间到该展台近景 + 弹出与热点共用的说明卡
- 说明卡内容来自 `src/story.js`，与 3D 展台共用同一份数据

## 4. 涉及文件

| 文件 | 改动 |
|---|---|

## 5. 验证与风险

- `npm run build` 通过；
- 未跑浏览器实测，重点确认：
  1. 五座展台是否落在左墙前、有没有被柱子/屏风挡住；
  2. 道具的符号是否读得出来（笔、槌、青、坛、绣球）；
  3. 点击章节后相机是否对准展台、说明牌是否在画面里；
  4. 走进长廊时会不会被展台碰撞卡住。
