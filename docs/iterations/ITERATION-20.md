# ITERATION 20 · 按键提示、故事道具换生成资产、过门修复

- 日期：2026-11-02
- 触发原因：动作区缺少按键提示；故事展台的道具是基础几何，观感差；推门后没进街市，反而回到初始界面。
- 结果：三个问题都已处理。

---

## 1. 动作区按键提示

动作面板底部新增一条半透明按键条：

```
W A S D 移动   Shift 奔跑   Space 跳跃   C 蹲伏   X 滑铲
```

样式与面板一致（细边框 + 暗底 + 金色键帽），不抢视觉，但能直接告诉观众漫游怎么操作。

## 2. 故事展台道具换成 Lux3D 资产

五座展台原来的道具（笔、鼓槌、生菜、酒坛、绣球）是基础几何，改成 `text-to-3d` 生成：

| 展台 | 提示词 | 任务 | 体积 |
|---|---|---|---|
| 点睛 | 中国毛笔斜放在朱砂砚台上 | 4586827 | 17.3MB |
| 起势 | 一对交叉摆放的木质鼓槌 | 4586830 | 17.9MB |
| 采青 | 一棵生菜用红绳捆着，旁边一个利是封 | 4586832 | 21.5MB |
| 醉狮 | 陶制酒坛，红布封口，麻绳 | 4586836 | 23.0MB |
| 收势 | 刺绣绣球，红金配色，带流苏 | 4586838 | 21.0MB |

接入方式（`story-gallery.js`）：

- 先用程序化道具占位，GLB 加载完成后**替换**并释放占位几何；
- 生成资产按最长边 0.72 单位归一化、居中、底面贴台面；
- 加载失败时保留占位，不阻塞展厅。

## 3. 过门修复

之前推门会触发 3DGS 覆盖层，初始化 20 秒超时后回退到漫游起点，于是「卡出来到初始界面」。

现在：

- **移除自动触发的 3DGS 覆盖层**，过门直接留在漫游状态，走进程序化街市；
- 过门时提示「已进入长安街市：街上三个行人会来回走」；
- `splat-street.js` 与 `street.spz` 保留在仓库，但不再默认加载，避免 CPU 环境卡死；
- 实测：过门后 `body[data-mode]=roam`、`#splatStage` 保持隐藏、坐标停留在街市一侧、控制台无错误。

## 4. 涉及文件

| 文件 | 改动 |
|---|---|

| `src/environment/story-gallery.js` | 生成资产加载与占位替换 |
| `public/models/story-*.glb` | 五个生成道具 |

## 5. 待确认

- 生成道具的朝向与尺寸是按包围盒估的，摆上台面后可能需要微调（`loadStoryModel` 里的 0.72 与旋转）；
- 街市目前是程序化几何 + 三个行人；如果后续要 3DGS，建议先用全景图方案（见 ITERATION-19）。
