# ITERATION 06 · 背景盘龙

- 日期：2026-11-01
- 触发原因：用户补充了 `public/models/龙.glb`，希望作为背景内容融入展厅。
- 本轮目标：不打断主角展示的前提下，把龙做成背景装置。

---

## 1. 资产情况

| 项目 | 值 |
|---|---|
| 文件 | `public/models/龙.glb` |
| 大小 | 19.4 MB |
| 网格 | 1 个 mesh，无骨骼（skins=0） |
| 动画 | 无 |
| 材质 | 1 套 PBR，内嵌 2 张贴图 |
| 原始包围盒 | 0.45 × 0.39 × 0.42（近似球形，应为盘龙造型） |

## 2. 做法

新增 `src/environment/dragon-ornament.js`：

- **延迟加载**：首屏 2.8s 后再请求，避免和 15MB 的主角模型抢带宽；
- **归一化**：按最长边缩放到 3.0 单位，居中后挂在展厅根节点；
- **摆放**：`(0, 5.85, -9.1)`，月亮门前方、角色上方偏后，不挡中央展台；
- **动态**：没有动画，于是给极慢的自转（0.045 rad/s）和 ±0.14 的上下浮动，读起来像悬浮装置；
- **材质**：`envMapIntensity` 压到 0.55，避免背景过亮抢主体；不投影，省性能；
- **清理**：随展厅一起 dispose，不残留几何与贴图。

接入点：`procedural-hall.js` 的 `createProceduralHall()` 里创建、`update()` 里驱动、`dispose()` 里释放。

## 3. 注意事项

- 龙是静态网格，位置与朝向是估算的，如果看起来偏了（挡住匾额、穿进柱子、离得太远），改 `dragon-ornament.js` 顶部的 `DRAGON.position` / `span` 即可；
- 19.4MB 是纯装饰资产，弱网下会明显占用带宽；若现场网络差，可以把它改成按需加载或压缩后再用；
- 背景龙不参与碰撞，第一人称漫游时可以从下方穿过。

## 4. 验证

- `npm run build` 通过；
- 未跑浏览器实测，建议确认：龙是否出现在月亮门前上方、亮度是否合适、旋转时是否与柱子/匾额穿插。
