# ITERATION 25 · SpatialGen 全景兜底；街市继续放大（未收尾）

- 日期：2026-11-02
- 触发原因：3DGS 全黑，需要能看的 SpatialGen 空间；街市要更大，容纳酒楼/阁楼/门楼。

---

## 1. 全景查看器（已完成，可用）

3DGS 路线确认不可行：

- `street.spz` 是 SPZ v3，`gaussian-splats-3d@0.4.7` 只支持 v2 → 解析直接报错；
- 换 `street.ply`（32.4MB，500,114 splats）后能加载（10–14s），但画面全黑，CPU 环境下无法确认是取景还是软件渲染问题。

于是改用 World 详情里的 `panoUrl`：**1.1MB，等距柱状全景，秒开**。

- 新模块 `src/pano-street.js`：Three.js 球面贴图 + 拖拽环视 + 滚轮缩放；
- 按钮「SpatialGen 街景（全景）」打开，左上角返回；
- 实测截图：灯笼、店铺、行人清晰可见，就是 SpatialGen 生成的那条街。

## 2. 街市放大（改了，但观感未验证）

- 街宽 26（`halfWidth`），长度到 `50`，城门在 `47`；
- 店铺改为**两层**：下层 7.2×4.4，二层木构 6.6×3.0，加飞檐与栏杆；
- 店距 8.2，两侧各三间；
- 补光：新增方向光 + 半球光（街市在展厅外，主场景灯照不到）；
- 移除生成式酒楼/门楼的摆放：它们的包围盒包含背景大平面，归一化后比例失真。

## 3. 仍未解决

无头浏览器截图里，街市依然是一大片雾色空地 + 几个行人，看不到两侧楼体。场景树里街市有 68 个 mesh，对象存在，但视觉上不出现。

已排除：hall 遮挡（按名字隐藏 hall 后画面不变）。

未排除：

1. 相机跟随与视场：36° 竖直 FOV，两侧楼在画面外；
2. 雾 `FogExp2 0.022` 在 15–20 米处吞掉立面；
3. 街市材质在补光下仍过暗。

## 4. 建议的下一步

把街市做成**独立场景**（自己的相机、灯光、雾），而不是复用展厅的 scene 与跟随相机；
这样构图、曝光、雾都能单独调，不会再和展厅互相干扰。工作量约半天。
