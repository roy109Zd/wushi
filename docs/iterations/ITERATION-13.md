# ITERATION 13 · 找到门、走顺路、收掉多余屏风

- 日期：2026-11-02
- 触发原因：门太隐蔽、角色移动手感差、屏风挡得太多。
- 本轮目标：把门做成肉眼可见的引导，重调移动手感，屏风减到两片。

---

## 1. 门：从"藏起来"到"看得见"

之前门只是右墙上一个洞，没有任何提示。现在加了四层引导：

- **红毯**：从 x≈7.8 一直铺到门口（12 长、1.5 宽、暗红自发光），顺着走就能到
- **门匾**：门洞上方一块 Canvas 文字牌「街 市 / MARKET →」，朝向厅内
- **门灯**：门洞两侧各一盏红灯笼
- **门光**：门口一盏暖色点光（强度 26、范围 10），在暗墙里形成一个亮口
- 进入漫游时的提示也改成「沿红毯走到右侧朱门可去街市」

## 2. 移动手感

- 速度改为**阻尼加速**：起步与收步不再瞬移，`1 - e^(-9t)` 逼近目标速度
- 转身速度 2.3 → 2.6 rad/s
- 行走 2.6、奔跑 5.2
- 相机跟随从 8 单位 / 4.4 高收到 **7.2 / 4.0**，平滑系数 4.5 → 9（跟得更紧，转向不拖影）
- 停下时速度降到 0.25 以下才收动画，避免频繁起停

## 3. 屏风减半

- 四片 → **两片**：删掉贴墙的两片，只保留前区斜屏
- 尺寸 5.0×3.2 → **4.4×3.0**
- 位置从 ±12.8 外移到 **±14.6**，朝向 1.15 → 1.35（更贴墙，少挡视线）
- 碰撞半径 2.3 → **1.8**
- 对应的点击说明与相机焦点同步更新

## 4. 涉及文件

| 文件 | 改动 |
|---|---|
| `src/environment/procedural-hall.js` | 红毯、门匾、门灯、门光；屏风减半与碰撞；焦点更新 |
| `src/roam.js` | 阻尼速度、转身与跟随参数 |
| `src/main.js` | 漫游提示文案 |

## 5. 验证

- `npm run build` 通过；
- 未跑浏览器实测，请确认：
  1. 从展台能否一眼看到红毯和「街市」门匾；
  2. 顺着红毯能否直接走出门；
  3. 起步/收步是否顺滑、转身镜头是否还晕；
  4. 两片屏风是否还挡主角。
