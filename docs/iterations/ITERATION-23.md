## 2. 还没确认的

无头浏览器（纯 CPU）截图里，沿街看过去两侧建筑不明显，只看到行人和地面；但场景树里街市有 60 个 mesh，建筑对象确实存在。

可能原因（未验证）：

1. 相机跟随距离 7.2，加上 36° 视场，沿街平视时两侧立面落在画面边缘之外；
2. 雾（`FogExp2 0.022`）在 15–20 米处把立面压成背景色；
3. 生成建筑的包围盒归一化后实际尺寸偏小，位置对但视觉体量不够。
